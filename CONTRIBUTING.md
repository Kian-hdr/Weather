# Contributing

Weather is created and maintained by Kian Konrad. Contributions are welcome under the project's MIT license.

- Keep the app native, accessible and useful without location permission.
- Preserve the quiet interface, clear source attribution and honest offline/forecast timestamps.
- Never add analytics, accounts, advertising, new paid services or background location without discussion.
- Include a focused regression test for behavioral fixes. Run the JVM tests and lint; use an emulator for UI tests.
- Mark test fixtures clearly. Never publish private locations, credentials, signing keys, internal logs or personal records.
- Keep provider licenses and usage limits intact. Changes to dependencies must update the dependency inventory and bundled notices.

Please open an issue to discuss large changes before submitting a pull request. Include Android/app versions and reproduction steps with bug reports.
