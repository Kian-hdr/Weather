# Security

Please use GitHub's private vulnerability reporting for security issues. Do not put credentials, exact private locations or personal data into public issues.

Download official APKs only from this repository's Releases page. Release checksums and the signing-certificate fingerprint are published so downloads and compatible updates can be verified.

Weather connects directly to third-party weather and map providers. Their service availability, privacy practices and terms are independent of this project. The app does not collect analytics or run a location-tracking backend.
